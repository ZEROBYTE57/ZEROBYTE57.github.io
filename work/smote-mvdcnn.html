SMOTE-Enhanced Multi-View Deep CNN for Mammogram Classification

Completing missing mammogram views to train a four-view CNN.

A 2.24M-parameter multi-view (CC and MLO) CNN for benign and malignant classification on CBIS-DDSM (1,566 patients), with stratified patient-level 70/15/15 splits.

The problem

A screening mammogram has four views: CC and MLO of each breast. Multi-view models use all four, but in CBIS-DDSM only 105 of 1,566 labelled patients have all four views; most cases miss two. Throwing those away leaves too little data, and the remaining classes are imbalanced.

The approach

  1. Pre-processing: DICOM to PNG, CLAHE contrast enhancement, resize to 224×224, grouped into patient-level cases.
  2. SMOTE view completion: a missing view is synthesised by donor-based convex interpolation between similar patients with the same label (Beta(2,2) blending, quality-checked with SSIM and correlation). Complete four-view cases grow from 105 to 1,223.
  3. Hybrid class balancing: undersampling plus case-level SMOTE oversampling, giving 1,122 cases (561 benign, 561 malignant).
  4. MV-DCNN: four separate branches (Conv3×3 + BN + ReLU, 32/64/128/256 filters) fused into a 1024-D vector and a small fully connected head: 2.24M parameters.
  5. Training: Adam, BCE-with-logits, learning-rate scheduling on plateau, early stopping, patient-level 70/15/15 split.

Results

The final Tier-2 model reached 84.02% accuracy, 78.79% precision, 92.86% recall, 75.29% specificity, 85.25% F1 and 93.24% AUC on the held-out test set (169 patients).

Limitations and honesty notes

  • View completion runs before the split, so a test patient's synthetic view can be built from training-set donors. Labels never leak, because donors share the target's label, and the evaluation also reports metrics on the real-views-only test subset.
  • The original code was lost; the public repository is a faithful rebuild from the thesis report and presentation, with the assumed settings clearly marked in the config.
