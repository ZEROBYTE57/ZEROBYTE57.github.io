LLM Response Preference Prediction

Predicting which of two chatbot answers a human preferred.

Predicting which of two LLM answers a human preferred (A, B or tie) on 57K Chatbot Arena battles across 64 LLMs, evaluated on log loss.

The problem

Given a user prompt and two responses from different LLMs (A and B), predict which response a human preferred: A, B or a tie. It is a 3-class probabilistic classification on pairwise text, scored on log loss (lower is better).

The catch: the training data names the models, but the test set does not, so predictions have to come from the text itself.

What I did

  1. Exploratory analysis. Found 64 distinct models across both sides of the 57,477 battles (no model ever plays itself), counted wins, losses and ties per model and position, and compared per-model win rates in side-by-side heatmaps.
  2. Pipeline fixes. Fixed a loss count computed with the win formula; found that the test set has no model columns, so per-model win rates cannot be used directly; removed an ID-to-model pairing that broke submissions on the hidden test set.
  3. Validated baseline. Built a submission pipeline that predicts the training class priors, with checks for column order, row count and missing values, and fixed a Kaggle "incorrect format" scoring error.

Next steps

  • Text features: TF-IDF on the prompt and both responses, plus response length and word counts.
  • Model attribution: predict which model most likely wrote each response from its text, then use that model's regularised win rate.
  • Fine-tuning: train a transformer on the prompt and both responses and compare it with the baselines on log loss.
